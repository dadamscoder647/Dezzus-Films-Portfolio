# Special projects

Use this folder for future Dezzus Universe code projects in the existing
Dezzus-Films-Portfolio repository. Reuse the existing photography website;
keep its files intact while planning any connection to Dezzus Universe.

## Start a project

1. Copy `project-template/` to a descriptive folder here, such as `gallery-integration/`.
2. Replace the copied README placeholders with the project's purpose, owner,
   setup instructions, validation steps, and review status.
3. Put application code in that project's `src/` folder. Document dependencies
   and configuration requirements without including secret values.
4. Prepare changes on a working branch for review. Merging, deployment, and
   public gallery publication require their own explicit authorization.

## Private material

Keep original photographs, private review galleries, downloaded Pixieset
collections, credentials, and secrets outside this repository. The 218 privately
downloaded Pixieset photos are not project source files and must not be committed
to GitHub. Reference approved storage locations without exposing private links
or access credentials.

Before committing, inspect both the changed files and any staged diff. An ignore
rule does not protect a file that is already tracked. Use placeholders for
configuration examples and supply actual secrets through environment settings.
Only use public gallery assets after approval of the exact gallery and assets.
